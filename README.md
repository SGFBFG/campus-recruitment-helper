# 校招任务管理

一个简洁好用的校招任务管理桌面软件，帮你追踪秋招/春招过程中的测评、笔试、面试、材料等各类任务。

## ✨ 功能特性

- **任务管理**：新增、完成、删除校招任务，支持按类型筛选
- **自动同步**：每 15 秒自动同步数据，可与邮箱自动收集任务配合使用
- **新任务提醒**：新收到的任务弹窗提醒 + 高亮动画
- **链接直达**：每条记录可附带测评/面试链接，一键打开
- **统计看板**：全部、待完成、3天内截止、本周要做、已完成 — 一目了然
- **排序筛选**：按收到日期/截止日期排序，按类型和状态筛选
- **本周高亮**：本周内截止的任务自动蓝色高亮
- **数据安全**：原子写入 JSON 数据文件，避免损坏
- **精美界面**：现代化 UI 设计，流畅动画

## 🖥️ 界面预览

- 顶部统计卡片，快速了解任务概况
- 列表视图，支持排序、筛选、操作
- 新增任务弹窗，填写公司、类型、内容、链接、日期等
- 蓝色高亮本周截止任务，橙色提醒 3 天内紧急任务

## 🚀 快速开始

### 环境要求

- Python 3.8+
- Windows 系统（pywebview + .NET 后端）

### 安装依赖

```bash
pip install pywebview
```

### 运行

```bash
python 校招任务管理.py
```

### 打包为 EXE

使用 PyInstaller 打包：

```bash
pip install pyinstaller
pyinstaller 校招任务管理.spec
```

打包后的文件在 `dist/` 目录下。

## 📁 数据文件

数据保存在程序同目录下的 `校招任务数据.json` 文件中，格式为 JSON 数组。

每条任务包含以下字段：

| 字段 | 说明 |
|------|------|
| id | 唯一标识 |
| company | 公司名称 |
| type | 类型（测评/笔试/面试/材料/其他） |
| detail | 内容说明 |
| received | 收到日期 |
| deadline | 截止日期 |
| link | 相关链接 |
| done | 是否已完成 |

## 🏗️ 技术栈

- **后端**：Python + 内置 HTTP 服务
- **前端**：原生 HTML / CSS / JavaScript
- **桌面容器**：pywebview
- **打包工具**：PyInstaller

## 📝 架构说明

程序采用本地 HTTP 服务 + 前端页面的架构：

1. Python 启动一个本地 HTTP 服务（127.0.0.1:随机端口）
2. pywebview 创建窗口加载页面
3. 前端通过 fetch 轮询 `/api/items` 获取数据
4. 新增、完成、删除等操作通过 POST 请求完成
5. 数据以 JSON 文件形式保存在本地

这种架构的好处：
- 前后端分离，界面与逻辑解耦
- 同源策略无 CORS 问题
- 可与外部程序（如邮箱自动收集脚本）共用数据文件
